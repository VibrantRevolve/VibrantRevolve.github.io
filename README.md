# VibrantRevolve website

Static site (HTML, CSS, JavaScript). Host it free on GitHub Pages or Cloudflare Pages.

- `SETUP.md` explains checkout links, PayPal, the banner, the auto blog and the admin.
- Products: `assets/data/products.json`. Banner: `assets/data/banners.json`. Blog: `blog/posts.json`.
- Store and payment settings: `assets/js/site-config.js` (public values only; never commit secret keys).
- Shared header and footer: `components/`.
- Contact forms open the visitor's email app until EmailJS keys are added in `assets/js/contact.js` and `index.html`.

- Studio Tools: `tools/` (Logo Maker, Name Generator, Copy Writer, Palette Extractor, Invoice Maker, QR) and `brand-studio/`. See SETUP.md section 7.
